# Carbon Tech

네더라이트 이후의 엔드게임 신소재 장비 모드. **가벼움, 높은 탄성, 초고속, 충격 흡수**가 핵심 키워드입니다.

- Minecraft **1.21.1** / **Fabric Loader 0.19+** / **Fabric API** 필요
- 라이선스: CC0-1.0

## 설치

| 필요한 것 | 다운로드 |
|---|---|
| Fabric Loader (1.21.1) | https://fabricmc.net/use/installer/ |
| Fabric API (1.21.1) | https://modrinth.com/mod/fabric-api/versions?g=1.21.1 |
| Carbon Tech | https://github.com/Elva-P/carbon-tech/releases/latest |

1. Fabric 설치 프로그램을 실행해 게임 버전 **1.21.1**을 선택하고 Install을 누릅니다.
2. 런처에서 `fabric-loader-1.21.1` 프로필을 한 번 실행해 타이틀 화면까지 띄운 뒤 종료합니다. (mods 폴더가 생깁니다)
3. `fabric-api-*.jar`와 `carbontech-*.jar`를 `mods` 폴더에 넣습니다.
   - 윈도우: `%appdata%\.minecraft\mods`
   - 맥: `~/Library/Application Support/minecraft/mods`
4. 같은 프로필로 실행하면 타이틀 화면의 Mods 버튼에 Carbon Tech가 보입니다.

한 번에 설치하려면 릴리스 페이지의 `.mrpack` 파일을 [Modrinth 앱](https://modrinth.app)으로 열면 로더, Fabric API, 모드가 자동 설치됩니다.

## 테크트리

| 단계 | 내용 |
|---|---|
| 카본 원광석 | 다이아몬드와 같은 분포(Y -64에서 가장 많고 16까지 감소)이되 약간 더 희귀. 돌 층은 카본 원광석, 심층암 층은 심층암 카본 원광석. **다이아몬드 이상 곡괭이** 필요 (그 이하로 캐면 드롭 없음). 채굴 시 카본 원석 드롭 |
| 카본 주괴 | 카본 원석을 **고열 용광로**에서 제련 (일반 화로 불가) |
| 탄소 섬유 | 주괴 1개 → 섬유 4개 |
| 탄소 막대 | 섬유 2개 세로 배열. 모든 카본 도구의 손잡이 |
| 카본 블록 | 주괴 9개. 비콘 베이스로 사용 가능 |
| 카본 업그레이드 형판 | **고대 도시 상자**(30%)에서 획득. 다이아몬드 7 + 심층암으로 복제. 대장간에서 네더라이트 장비 + 카본 주괴 → 카본 장비 (인챈트·내구도 유지) |

카본 장비는 주괴와 탄소 막대로 직접 제작할 수도 있고, 형판으로 네더라이트 장비를 업그레이드할 수도 있습니다.

## 장비

내구도 2,031 (네더라이트와 동일). 네더라이트보다 가벼워 공격/채굴 속도가 약간 빠릅니다. 용암에 타지 않는 속성은 없습니다.

| 장비 | 특징 |
|---|---|
| 카본 검 | 공격력 10.5, 공격 속도 1.7 (네더라이트 8 / 1.6) |
| 카본 곡괭이 | 채굴 속도 9.9 (네더라이트보다 10% 빠름) |
| 카본 도끼 / 삽 / 괭이 | 네더라이트보다 공격 속도 +0.1 |
| 카본 방어구 4종 | 방어력·강인함은 네더라이트와 동일. 차별점은 전용 인챈트 |
| 카본 방패 | 내구도 672 (바닐라 2배). 도끼 무력화 3초 (바닐라 5초). 카본 주괴로 수리 |
| 카본 활 | 당김 시간 14틱 (바닐라 20틱, 30% 단축). 내구도 768. 탄소 섬유로 수리 |

## 전용 인챈트

| 인챈트 | 대상 | 레벨 | 효과 |
|---|---|---|---|
| 고탄성 | 방어구 | I | 레깅스: 신속 I 상시 / 부츠: 점프 강화 I + 낙하 피해 50% 감소 + **2단 점프** / 투구: 메이스 강타 무효 / 갑옷: 넉백 80% 감소 |
| 충격 흡수 | 갑옷, 레깅스 | I ~ III | 최종 데미지 레벨당 5% 감소 (갑옷 + 레깅스 합산, 최대 30%) |
| 탄성 강화 | 검, 도끼 | I ~ V | 레벨당 +1 데미지. 달리면서 공격 시 보너스 1.5배 |
| 진동 흡수 | 곡괭이, 삽, 도끼 | I | 15% 확률로 내구도 소모 없음 |
| 탄성 충격 | 곡괭이, 삽 | I ~ III | I: 뒤 1칸 관통 / II: 관통 + 위 1칸 / III: 바라보는 면 기준 3x3. Shift 누르면 단일 채굴 |

카본 장비는 모루 합성 시 **날카로움, 효율, 보호를 VII**까지 올릴 수 있습니다 (V + V → VI, VI + VI → VII). 마법 부여대에서는 바닐라 상한까지만 나옵니다.

## 발전 과제

카본 테크 탭: 카본 테크 → 탄소의 시대 → 탄성의 시위 / 고대의 설계도 / 검은 갑주 → 한계 돌파

## 개발

```bash
./gradlew build        # build/libs/carbontech-1.0.2.jar
./gradlew runClient    # 개발용 클라이언트 실행
python3 tools/make_textures.py   # 임시 텍스처 재생성
```

Gradle(Loom 1.18)은 Java 25로 실행되고, 모드 코드는 Java 21 대상으로 컴파일됩니다. `gradle.properties`의 `org.gradle.java.home`을 본인 환경의 JDK 25 경로로 맞춰 주세요.

### 구조

- `item/` 아이템, 도구·방어구 재료, 방패, 활
- `block/` 카본 원광석, 카본 블록
- `enchantment/` 전용 인챈트 효과 핸들러 (정의는 `data/carbontech/enchantment/*.json`)
- `mixin/` 최종 데미지·넉백, 모루 레벨 상한, 방패 내구도
- `world/` 광석 월드 생성, 고대 도시 전리품
- `client/` 방패 3D 렌더러, 활 당김 애니메이션, 2단 점프 입력
- `network/` 2단 점프 패킷
